# FinConnect Frontend

A modern, premium financial dashboard built with React + Vite + TailwindCSS + ShadCN UI.

## Features

- 🎨 **Premium Dashboard Layout**
  - Responsive sidebar with icons
  - Top navbar with search and user profile
  - Beautiful animated transitions
  - Card-based dashboard design

- 📊 **Charts & Visualizations**
  - Recharts integration
  - Real-time market data
  - Financial metrics visualization

- 🎯 **UI Components**
  - ShadCN UI components
  - TailwindCSS styling
  - Smooth animations
  - Dark mode support

## Tech Stack

- **React 19** - UI library
- **Vite 7** - Build tool
- **TailwindCSS 4** - Styling
- **ShadCN UI** - Component library
- **React Router DOM** - Routing
- **Axios** - HTTP client
- **Recharts** - Chart library
- **Lucide React** - Icons

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```

## Environment Variables

Create a `.env` file in the root directory:

```env
VITE_API_URL=http://localhost:5000
```

## Project Structure

```
src/
├── api/           # API clients and endpoints
├── components/    # React components
│   ├── ui/        # ShadCN UI components
│   └── layout/    # Layout components (Sidebar, Navbar)
├── pages/         # Page components
├── charts/        # Chart components
├── lib/           # Utility functions
└── utils/         # Helper utilities
```
